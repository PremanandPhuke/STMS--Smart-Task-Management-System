# pages/

One file per screen (each is mapped to a URL in `App.tsx`).

| Page | URL |
|---|---|
| `LoginPage`, `RegisterPage` | `/login`, `/register` |
| `DashboardPage` | `/` |
| `ProjectsPage` | `/projects` |
| `ProjectBoardPage` | `/projects/:id` (Kanban board with drag and drop) |
| `TasksPage` | `/tasks` (search, filters, sorting, pagination) |
| `LabelsPage` | `/labels` |
| `AdminPage` | `/admin` (ADMIN only) |
